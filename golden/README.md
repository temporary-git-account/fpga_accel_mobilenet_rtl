# Numerical fixtures

`model_spec.json` records tensor shapes, layouts, zero points, per-channel
multipliers, shifts and activation bounds for 37 operators. `model_constants.npz`
and `softmax_lut.npy` are hash-checked by the reference. The convolution engine
implements 28 operators; graph simulation provides the other numerical steps.

`quant_cases.hex` / `quant_cases.svh` contain 40,815 arithmetic test cases.
`pointwise_quant.hex` and the MAC vector files exercise an earlier arithmetic
tile. `integer_validation.json` records seven inputs × 37 expected tensor hashes.
Four prepared RGB inputs are included; black, white and seeded-random inputs
are generated by the numerical tools when needed.

The arrays are test stimuli and expected numerical data. They are not generated
bitstreams, timing constraints or a guarantee for arbitrary future models.
